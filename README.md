# MRS Bulletin Phase Retrieval ABCs

This repository contains code and manuscript sources associated with the paper:

**The ABCs of Phase Retrieval: Connecting the Acronyms of Scanning Transmission Electron Microscopy**

## Contents
  
- Manuscript source files written in Typst
- Jupyter notebooks for reconstruction, analysis, and figure generation

## Data

The calibrated experimental datasets used in this work are available on Zenodo: https://doi.org/10.5281/zenodo.18449975.
The notebooks in this repository assume access to these datasets.
